# AI SOC Copilot

## Project Overview

AI SOC Copilot is an AI-powered Security Operations Center (SOC) assistant that helps security analysts detect, analyse, and explain cyber threats using Machine Learning and Large Language Models.

## Technologies

- Python
- FastAPI
- Pandas
- NumPy
- Scikit-learn
- LangChain
- Ollama
- FAISS
- Streamlit
